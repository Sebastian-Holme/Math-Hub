# MA:KI — Math-Hub

[Åpne live-siden](https://sebastian-holme.github.io/Math-Hub/)

**Innhold:**
En interaktiv webapplikasjon for å visualisere matematikk, algoritmer og andre kjernekonsepter fra et informatikk-studieløp. Appen er delt inn etter semester (1–6), og hvert emne har egne interaktive verktøy man kan utforske direkte i nettleseren — blant annet lineær algebra og matriser, derivasjon, kretsanalyse, IP/subnett-beregning, lineær regresjon og gradient descent, nevrale nettverk, datastrukturer (lenkede lister, rekursjon, tråder), sannsynlighetsfordelinger og hypotesetesting.

**Teknologi:** React, TypeScript, Tailwind CSS v4, Framer Motion, Vite.
